# Major's Spelling Adventure

A lightweight, responsive static website game for children aged 7–8.

## Run it
- Open `index.html` in a modern browser, or upload the folder to GitHub Pages, Netlify, or Vercel.
- No server, database, account, or API key is required.
- Internet is not required after the files are downloaded; speech synthesis availability depends on the browser/device.

## Game features
- Categories: Food, Animals, School, Nature, At Home, Surprise Mix
- Three levels: multiple-choice recognition and two spelling challenges
- Word pronunciation using browser speech synthesis (English UK voice requested; device voices may vary)
- Hints, emoji clues, stars, progress bar, and end-of-round score
- Responsive design for phones, tablets, and computers

## Important note
The browser's built-in speech synthesis provides approximate pronunciation, not a recorded teacher. For classroom use, an adult should check pronunciation and help children sound out unfamiliar words.
